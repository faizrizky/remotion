# docs/ index

Docs are grouped per channel. Each channel folder holds its own master rules file.

- `penny-logics/` - finance channel. Rules: `penny-logics/PENNY_LOGICS_RULES.md`. Also `channel/` (distribution, topic research, upload calendar), `archive/`, and one folder per video (`video01` ... `video04`).
- `rule-zero/` - rules-horror story channel (not finance). Rules: `rule-zero/RULE_ZERO_RULES.md`, series bible and reference teardown.
- `shared/` - material used by both channels (e.g. `SCENE_PROMPT_LIBRARY.md`).

Assets follow the same split: `Assets/penny-logics/` and `Assets/rule-zero/`.
