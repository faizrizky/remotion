## SHORT 1: underwater (loop)
Hook layar: "$7,107 UNDERWATER?" (detik pertama). Alt: "Owe more than your car's worth?" / "3 in 10 trade-ins owe more than the car."
```
Seven thousand dollars underwater on your car? //
Almost three in ten trade-ins owe more than the car is worth. //
Roll that into a new loan, / and lifetime interest averages sixteen thousand six hundred. //
Nine in ten stretch it past six years. //
So ask for the TOTAL interest, / not the payment, /
when you're seven thousand dollars underwater
```
56 kata, ~19 dtk. Ending menggantung, loop ke baris pertama. Sumber: Edmunds Q3 2026 (29,1%; selisih rata-rata $7.107; bunga seumur pinjaman gulir $16.610; 91,2% > 72 bulan). [check: buka halaman Edmunds sekali sebelum rekam.]
Shot (vertikal, 2-3 scene, perkiraan): 0-3 papan "VALUE / LOAN" + pill $7,107 (Leo tidak wajib) | 3-8 29.1% bar + SrcPill | 8-14 kartu kontrak + MoneyPile "+$16,610" | 14-19 pill "ASK: TOTAL INTEREST", frame akhir = frame awal. Subtitle 1-3 kata per baris, aman x 80-1000, y 220-1500.

## SHORT 2: kuis dua cicilan (loop)
Hook layar: "$625/MO or $813/MO? WHICH COSTS MORE?" Alt: "Same car. Two loans. Which costs more?"
```
Which loan costs more: / six twenty-five a month, / or eight thirteen? //
Same forty-thousand-dollar car, / eight point one percent. //
Eight thirteen is five years. / Six twenty-five is seven. //
Interest: eighty-eight hundred, / versus twelve and a half thousand. //
So the CHEAPER payment costs almost four thousand more. //
Before you sign, always ask: / which loan costs more
```
54 kata, ~18-19 dtk. Loop ke "Which loan costs more:". Hitungan ilustrasi (label "example"): 60 bln $812.97 bunga $8,778; 84 bln $625.44 bunga $12,537; selisih $3,759.
Shot: 0-3 dua kartu "$625 / $813" berdampingan (tetap vertikal: ditumpuk) | 3-12 batang bunga tumbuh $8,778 vs $12,537 | 12-16 "+$3,759" merah | 16-19 kembali ke dua kartu (frame awal).
